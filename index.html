01 · Sobre mí

Convierto ideas en productos digitales

Tengo 20 años y soy Técnico Superior Universitario (TSU) en Informática. Me apasiona construir cosas que la gente use: desde una página para tu negocio hasta un sistema completo con backend y base de datos.

Trabajo con PHP y Laravel, Python con Django y Odoo, JavaScript con Node.js, Next.js con TypeScript y SvelteKit, sobre bases de datos PostgreSQL y MySQL. Además tengo bases sólidas de programación orientada a objetos con Java.
